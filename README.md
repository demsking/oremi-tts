![Oremi Text to Speech Screenshot](https://gitlab.com/demsking/oremi-tts/blob/main/screenshot.png)

## Start

Start Oremi TTS:

```sh
docker run -d --name oremi-tts -p 5215:5212 demsking/oremi-tts
```

Open http://localhost:5215
